# Hi, I'm Jupe 👋

I'm a developer based in Jakarta. I work with core banking systems and also enjoy building web and Web3 projects.

Most of my projects use JavaScript, TypeScript, React, Next.js, Node.js, and Solana. I learn best by building things and solving real problems.
